SIP trunk

Every number on your account shares one dedicated trunk. Inbound calls only reach a device once you set an origination address below — a softphone with no fixed public address can't just "register" here; see the note under the form.

No trunk yet — provision a number first.

This must be the public SIP address of a PBX, session border controller, or a softphone with a stable, reachable address — Twilio's trunk API cannot accept a plain SIP REGISTER from an arbitrary device.
